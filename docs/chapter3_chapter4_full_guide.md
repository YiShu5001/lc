# 第三章与第四章完整信息设置指南

本文件用于统一第三章与第四章的论文安排、方法主线、章节职责、图表公式建议、代码映射与实验闭环。目标不是替代正式章节文本，而是作为后续写作、改稿、答辩准备和代码同步时的总纲。

## 1. 总体定位

整篇论文采用“规划层 + 控制层”的双层智能协同架构：

- 第三章负责下层执行问题：如何把高层意图稳定、平滑、抗扰地执行出来
- 第四章负责上层决策问题：如何在动态目标、障碍物与多机协同约束下生成合理规划动作

两章之间的衔接关系应始终保持为：

- 第四章输出规划参考量
- 第三章将参考量映射为底层执行控制
- 第三章不是孤立控制器改进
- 第四章也不是脱离动力学约束的纯策略网络
