# 第三章 RL 动作范围配置

## 1. 口径

第三章当前 `DDPG / mDDPG` 的动作语义固定为连续参数动作：

- `action[0] -> b0`
- `action[1] -> wc`
- `action[2] -> k`

其中：

- `wo = k * wc`
- `r` 当前固定，不进入 RL 动作

## 2. `x / y` 轴锚点

当前用于构造连续动作边界的两组锚点为：

### 快速任务锚点

- `b0 = 30.5`
- `wc = 1.5`
- `k = 11.0`
- `r = 10`

### 纯抗扰锚点

- `b0 = 4.0`
- `wc = 4.0`
- `k = 5.0`
- `r = 10`

## 3. `x / y` 轴动作范围

当前主链中正式配置为：

- `b0: 1.35 ~ 33.15`
- `wc: 1.25 ~ 4.25`
- `k: 4.4 ~ 11.6`
- `r: 10` 固定

这些范围来自：

- 快速任务锚点
- 纯抗扰锚点
- 再在两端增加约 `10%` 探索余量

## 4. `z` 轴动作范围

当前 `z` 轴仍采用更保守的单锚点口径：

- 快速/稳态锚点一致：
  - `b0 = 100`
  - `wc = 0.05`
  - `k = 0.5`
  - `r = 2`

当前主链中正式配置为：

- `b0: 85.0 ~ 115.0`
- `wc: 0.03 ~ 0.08`
- `k: 0.4 ~ 0.8`
- `r: 2` 固定
