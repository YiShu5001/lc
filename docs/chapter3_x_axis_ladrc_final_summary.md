# 第三章 `x` 轴 LADRC 参数整定总结

## 1. 文档目的

本文档总结当前第三章中 `x` 轴 `LADRC` 参数整定的最终口径、实验场景、当前保留参数，以及后续给 `DDPG / mDDPG` 设定连续动作范围时可直接使用的锚点参数。

当前代码实现位置主要在：

- `src/control/Tuning_ladrc/`
- `src/lc/control/simulators/`
- `src/lc/control/controllers/`

当前整定口径固定为：

- 控制器主体仍是 `LADRC`
- 强化学习后续仍输出连续参数动作：
  - `action[0] -> b0`
  - `action[1] -> wc`
  - `action[2] -> k`
- `r` 当前不进入 RL 动作，先固定为单值

## 2. 当前统一口径

### 2.1 参数定义

- `b0`：输入增益估计
- `wc`：控制器带宽
- `k = wo / wc`
- `wo = k * wc`
- `r`：TD 跟踪速度，本轮不参与搜索

### 2.2 当前固定值

为了减少维度、提高可解释性，当前 `x` 轴实验统一固定：

- `r = 10`

也就是说，当前 `x` 轴后续 RL 边界设计只围绕：

- `b0`
- `wc`
- `k`

## 3. 实验一：快速到达任务

### 3.1 场景设定

实验目标：在**无扰动**条件下，尽快从较大误差靠近目标，并在后段尽量稳定地贴近参考值。

控制场景：

- 总时长：`8 s`
- 控制频率：`48 Hz`
- 仿真频率：`240 Hz`
- 初始位置：`(x=0, y=0, z=1)`
- `y_ref = 0`
- `z_ref = 1`
- 无外力扰动

`x_ref` 设定为：

- `0 ~ 2 s`：`x_ref = 0`
- `2 ~ 8 s`：`x_ref = 0.12`

这个场景的语义是：

- 大误差快速靠近目标
- 到达后尽量减小稳态误差
- 同时控制振动和超调

### 3.2 当前保留的最优参数

当前该场景下保留的 `x` 轴快速任务参数为：

- `b0 = 30.5`
- `wc = 1.5`
- `k = 11.0`
- `r = 10`
- `wo = 16.5`

### 3.3 结果说明

该组参数是在 `8 s` 无扰动阶跃场景下，围绕原始 `x` 参数再次微调得到的结果。

当前特性：

- `rmse` 与 `PID` 基本持平
- `steady_state_error` 优于 `PID`
- 比早期 `x` 轴默认参数在“到达后误差残留”上更好

对应输出目录：

- `outputs/control_pybullet_manual_tuning/x_fast_task_refined/`

关键文件：

- `recommended_params.json`
- `summary.json`
- `figures/pid_vs_best_ladrc_time_response.png`

## 4. 实验二：纯抗扰任务

### 4.1 场景设定

实验目标：在**无阶跃**条件下，只考察无人机在持续外力干扰下的保持能力、扰动抑制能力和残余振荡大小。

控制场景：

- 总时长：`8 s`
- 控制频率：`48 Hz`
- 仿真频率：`240 Hz`
- 初始位置：`(x=0, y=0, z=1)`
- `x_ref = 0` 全程不变
- `y_ref = 0`
- `z_ref = 1`

外界扰动：

- 只作用在 `x` 轴
- 形式为额外外力，不是直接改位置
- 扰动力：
  - `d_x(step) = 0.05 * sin(0.11 * step)`

这个场景的语义是：

- 不考察目标切换
- 只考察外界干扰下能否稳住位置
- 更关注最后一段误差振幅和残余摆动

### 4.2 当前保留的最优参数

当前该场景下保留的 `x` 轴纯抗扰参数为：

- `b0 = 4.0`
- `wc = 4.0`
- `k = 5.0`
- `r = 10`
- `wo = 20.0`

### 4.3 评价口径

该实验后期已经不再只看 `rmse`，而是重点看：

- `steady_state_error`
- `final_error_std`
- `final_error_span`
- `control_variation`
- `rmse`

其中：

- `steady_state_error`：最后一段平均绝对误差
- `final_error_std`：最后一段误差标准差
- `final_error_span`：最后一段误差峰峰值

这组参数的意义是：

- 相比之前更激进的纯抗扰参数，平均误差明显压低
- 总体误差和恢复效果更好
- 已经可以作为“纯抗扰锚点参数”保留

对应输出目录：

- `outputs/control_pybullet_manual_tuning/x_disturbance_rejection_refined/`

关键文件：

- `recommended_params.json`
- `summary.json`
- `comparison_against_current.json`
- `final_compare/figures/pid_vs_best_ladrc_time_response.png`

## 5. 当前两套保留参数

### 5.1 快速到达参数

- `b0 = 30.5`
- `wc = 1.5`
- `k = 11.0`
- `r = 10`

适用场景：

- 有明显目标变化
- 需要尽快靠近参考值
- 同时要求到达后误差足够小

### 5.2 纯抗扰参数

- `b0 = 4.0`
- `wc = 4.0`
- `k = 5.0`
- `r = 10`

适用场景：

- 参考基本不变
- 存在持续外力扰动
- 更强调保持、抑制残余摆动和扰动恢复

## 6. 两套参数的本质区别

### 快速到达参数

对应问题：

- “我需要快速到目标附近”

它更偏向：

- 更大的控制尺度稳定性
- 目标切换时的靠近速度
- 到达后尽量减小残余误差

### 纯抗扰参数

对应问题：

- “目标不变，但外界一直在推我”

它更偏向：

- 持续扰动下保持
- 更小的残余摆动
- 更小的最后一段平均误差

所以这两套参数不是互相替代关系，而是：

- 一套用于“完成任务”
- 一套用于“抵抗扰动”

## 7. 对 RL 连续动作范围的意义

当前第三章后续如果要给 `DDPG / mDDPG` 设连续动作范围，建议直接用这两套 `x` 轴参数作为锚点。

### 锚点 1：快速到达参数

- `b0 = 30.5`
- `wc = 1.5`
- `k = 11.0`

### 锚点 2：纯抗扰参数

- `b0 = 4.0`
- `wc = 4.0`
- `k = 5.0`

后续 RL 仍然输出连续参数动作，而不是离散模式：

- `action[0] -> b0`
- `action[1] -> wc`
- `action[2] -> k`

建议后续边界构造方式为：

- `b0_range = [min(4.0, 30.5), max(4.0, 30.5)]`
- `wc_range = [min(1.5, 4.0), max(1.5, 4.0)]`
- `k_range = [min(5.0, 11.0), max(5.0, 11.0)]`

再根据训练稳定性决定是否在两端放宽 `10%`

## 8. 当前结论

当前 `x` 轴已经形成两套可保留参数：

### 快速任务参数

- `30.5 / 1.5 / 11.0 / 10`

### 纯抗扰参数

- `4.0 / 4.0 / 5.0 / 10`

当前建议：

- `r` 继续固定为 `10`
- RL 只学习 `b0 / wc / k`
- 后续先用这两套参数构造连续动作范围
- 不做离散模式学习
