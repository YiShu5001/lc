# LADRC 参数整定实验方案

本目录用于第三章 `LADRC` 参数手工整定，不参与主链 RL 训练。

## 目标

- 通过外部参数文件导入 `b0 / wc / k`
- 将参数注入单轴 `LADRC + 其余位置轴 PID + 姿态 PID`
- 用阶跃、保持、分段匀速等目标直接观察控制效果
- 为 `x / y / z` 三轴统一提供同一套整定流程

## 整定顺序

1. 先调 `b0`
   - 目标：让控制尺度正确，不飘、不冲、不过载
   - 现象判断：
     - 响应慢、控制量大：`b0` 偏小
     - 一推就飞、超调大：`b0` 偏大

2. 固定 `b0`，再调 `wc`
   - 目标：决定快慢和柔和度
   - 经验范围：
     - 悬停/精细定位：`3~8 rad/s`
     - 正常轨迹：`8~18 rad/s`
     - 高速飞行：`18~30 rad/s`

3. 固定 `b0 / wc`，最后调 `k = w0 / wc`
   - 默认先从 `k=4` 开始
   - 干扰大、恢复慢：提高 `k`
   - 噪声大、抖动重：降低 `k`

## 推荐实验流程

1. 阶跃目标
   - 用于先找 `b0`
   - 观察 rise/overshoot/steady-state error

2. 保持-阶跃-保持
   - 用于调 `wc`
   - 看速度、超调和稳定时间

3. 保持-阶跃-保持-反向阶跃
   - 用于调 `k`
   - 看切换段和回稳段

4. 分段匀速
   - 用于最终验证
   - 看持续跟踪和恢复能力

## 当前建议的实际执行顺序

1. `x` 轴先跑 `b0` 阶跃扫描
   - 固定 `wc / k`
   - 建议先试 `0.5x / 0.75x / 1.0x / 1.25x / 1.5x`
2. 根据曲线和指标选一个可用 `b0`
3. 再固定 `b0`，并固定 `k=4` 去调 `wc`
4. 最后固定 `b0 / wc` 去调 `k`
5. `x/y` 如果结果接近，可以保留同一套参数尺度
6. `z` 轴单独重复同样流程

## z 轴专用方案

`z` 轴不再直接照搬 `x/y` 的评分逻辑，而是采用“高度稳定性优先”的单独流程：

1. `z_hold`
   - 只看能否稳定悬停，不掉高
2. `z_small_step`
   - 小阶跃，例如 `+0.03m`
   - 用来调 `b0`
3. 固定 `k=4`，扫 `wc`
4. 固定 `b0 / wc`，扫 `k=2~6`
5. 最后用 `hold_step_hold(+0.05m)` 验证

专用指标优先级：
- `hover_error`
- `min_z_violation`
- `steady_state_error`
- `rmse`
- `overshoot`
- `control_variation`

## 操作建议

- `x / y` 轴先共用一套初值整定
- 如果 `x / y` 效果接近，可保留共用参数
- `z` 轴单独调
- 每次只改一个参数
- 不合适的参数直接记录现象，不要一边改多个量

## 外部参数文件

默认示例文件是 `default_axis_params.json`，字段格式：

```json
{
  "x": {"b0": 220.0, "wc": 1.1, "k": 8.7272727},
  "y": {"b0": 220.0, "wc": 1.3, "k": 7.3846154},
  "z": {"b0": 300.0, "wc": 15.0, "k": 7.3333333}
}
```

## 代码结构

- `parameter_loader.py`
  从 JSON 读取参数，并注入单轴 `LADRC` 控制器
- `target_profiles.py`
  生成阶跃、保持、反向阶跃、分段匀速目标
- `experiment_runner.py`
  运行单轴 `PID vs LADRC` 对比，输出图和指标
- `schemas.py`
  定义参数、目标配置和结果结构
