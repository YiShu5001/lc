# 第一章 绪论

## 1.1 研究背景与意义

### 1.1.1 多无人机协同控制的应用需求与挑战
随着无人机（Unmanned Aerial Vehicle, UAV）技术的飞速发展，其应用场景已从单机执行简单任务向多机协同执行复杂任务转变。在灾后搜救、编队巡检、物流运输及战场侦察等领域，多无人机系统（Multi-UAV System）凭借其分布式感知、高冗余度及强任务并行能力，展现出远超单机的作业效率与生存能力。

然而，在实际应用中，多无人机协同控制面临着严峻的挑战。首先，任务环境往往具有高度动态性与不确定性，障碍物分布密集且不可预测，这对系统的实时避障能力提出了苛刻要求。其次，多机协同要求个体在保证自身安全的同时，必须兼顾队形保持、任务分配等协作目标，导致“局部避障”与“全局协作”之间存在天然的耦合冲突。例如，在狭窄通道通行时，个体为了避障可能破坏队形，甚至引发拥堵或死锁。此外，实际物理环境中的风扰、气流干扰及模型不确定性，进一步增加了底层控制的难度，若底层控制无法稳定跟踪上层规划指令，整个协同系统的安全性将无从谈起。

因此，研究一种既能适应复杂动态环境、又能兼顾底层控制稳定性与上层协作效率的多无人机协同控制策略，具有重要的理论意义与工程应用价值。

### 1.1.2 强化学习在无人机控制中的优势与局限
近年来，深度强化学习（Deep Reinforcement Learning, DRL）因其强大的非线性映射能力和“试错”学习机制，在解决复杂决策与控制问题上展现出巨大潜力。与传统基于规则或优化的方法相比，DRL 能够直接从高维感知数据中学习端到端的控制策略，无需建立精确的环境数学模型，且具备更强的环境适应性。

尽管如此，将 DRL 直接应用于多无人机协同控制仍存在显著局限：
1.  **训练不稳定性与安全性缺失**：在连续控制任务中，纯 DRL 策略在探索初期往往输出剧烈波动的动作，极易导致无人机失稳或碰撞，且缺乏可解释的安全边界。
2.  **样本效率低与收敛困难**：多智能体环境的非平稳性（Non-stationarity）使得环境状态随其他智能体策略变化而变化，导致单一智能体难以获得稳定的价值估计，训练收敛极其缓慢。
3.  **多目标冲突**：当同时优化避障、队形、速度等多重目标时，奖励函数的微小变动都可能导致策略在不同目标间摇摆，甚至陷入局部最优。

### 1.1.3 持续学习视角下的关键问题
在多阶段或课程化训练中，DRL 往往面临“灾难性遗忘”（Catastrophic Forgetting）问题，即在学习新任务（如复杂协作）时，迅速遗忘旧任务（如基础避障）的能力。传统的经验回放机制（Experience Replay）难以有效应对多阶段任务分布的剧烈偏移。如何设计合理的经验管理机制，使系统在持续学习新技能的同时保持既有能力，是构建可进化协同系统的关键。

综上所述，构建一个分层解耦、底层鲁棒、上层协作且具备持续学习能力的控制体系，是解决当前多无人机协同难题的有效途径。

## 1.2 国内外研究现状

### 1.2.1 多无人机协同规划与避障方法
现有的多无人机避障方法主要分为传统方法与学习型方法两类。
传统方法包括人工势场法（APF）、动态窗口法（DWA）及基于几何规则的速度障碍法（VO/RVO）。这类方法计算量小、可解释性强，但在多机密集交互或强非线性环境中，容易陷入局部极小值导致死锁，且难以处理复杂的时空协同约束。
学习型方法，特别是多智能体强化学习（MARL），通过中心化训练去中心化执行（CTDE）框架，能够在一定程度上解决协作问题。然而，现有研究多关注高层决策，往往假设底层控制完美执行，忽视了动力学约束与环境扰动对策略执行的影响，导致“仿真不仅真，实飞飞不稳”。

### 1.2.2 分层强化学习在机器人控制中的应用
分层强化学习（Hierarchical Reinforcement Learning, HRL）通过将任务分解为不同时间尺度的子任务，有效降低了问题维度。在无人机控制中，典型的分层架构是：上层策略输出期望航点或速度指令，下层控制器负责动力学跟踪。
然而，当前的分层方法主要面临层间接口设计与误差传播的问题。若下层控制器在扰动下响应滞后，上层策略的学习效率将大幅下降；反之，若上层输出不可执行指令，下层控制器将长期处于饱和状态。因此，设计一个具有自适应能力的鲁棒底层控制器，是分层架构成功的基石。

### 1.2.3 鲁棒控制与自抗扰控制技术
线性自抗扰控制（LADRC）因其不依赖精确模型、能有效估计并补偿总扰动（Total Disturbance）的特性，在飞行器控制领域得到了广泛应用。然而，LADRC 的性能高度依赖于带宽、增益等参数的整定。传统固定参数的 LADRC 难以同时兼顾多种工况：高带宽响应快但对噪声敏感，低带宽抗噪好但抗扰性差。如何结合 RL 的自适应能力与 LADRC 的鲁棒结构，实现参数的在线寻优，是当前的研究热点。

### 1.2.4 经验回放与样本效率提升机制
经验回放是提升 DRL 样本效率的核心技术。优先经验回放（PER）通过赋予高 TD 误差样本更高的采样概率，加速了关键经验的学习。然而，在多阶段训练任务中，样本分布随课程难度递进而显著变化，单一的全局经验池容易导致样本覆盖不均，引发遗忘或过拟合问题。针对分层任务结构设计特定的经验存储与采样机制，目前尚缺乏系统性研究。

## 1.3 研究问题定义与挑战分析

### 1.3.1 协同避障中的“避障—合作”耦合冲突
在多机协同任务中，避障目标要求个体远离障碍物及邻机，而合作目标（如编队）则要求个体保持特定的相对位置。在狭窄空间或高密度障碍区，这两类目标存在天然的几何冲突。单一的标量奖励函数难以精确描述这种权衡，导致策略在训练过程中出现震荡，或倾向于牺牲某一类目标（如为了安全完全放弃队形）。如何实现任务目标的结构化解耦与融合，是本研究的首要挑战。

### 1.3.2 底层控制稳定性与上层探索的矛盾
上层规划策略需要通过广泛的探索（Exploration）来发现更优路径，但这往往意味着输出高频或大幅度的控制指令。如果底层控制器缺乏足够的鲁棒性，无法稳定跟踪这些指令，甚至导致姿态发散，那么上层策略收到的反馈将充满噪声，严重阻碍学习进程。构建一个“敢探索、能兜底”的底层控制闭环，是分层系统稳定训练的前提。

### 1.3.3 多阶段训练中的样本效率与遗忘问题
为了让无人机逐步掌握避障、队形与复杂协同能力，通常采用课程学习（Curriculum Learning）范式。然而，随着训练阶段推进，环境分布发生偏移，旧阶段的有效经验（如基础避障）在经验池中的占比会被新经验稀释，导致“学会了跑步忘了走路”。如何在提升样本效率的同时，系统性地克服灾难性遗忘，是实现持续学习的关键。

## 1.4 本文研究内容与总体框架

针对上述问题，本文提出了一种**基于分层强化学习的多无人机动态目标围捕协同控制策略**。总体思路采用“规划层—控制层”解耦架构，结合任务分离、自适应鲁棒控制与结构化经验机制，构建了一套高效、鲁棒且具备持续优化能力的协同控制系统。本文主要研究内容如下：

### 1.4.1 控制层：基于跨时间样本增强的 RL-LADRC 自适应控制器
针对底层控制在强扰动及模型不确定性下的稳定性问题，设计了以 LADRC 为骨架、RL 为参数调节器的自适应控制方案。
1.  利用扩张状态观测器（ESO）实时估计并补偿总扰动，保障基础鲁棒性。
2.  引入 RL 智能体根据当前状态误差与扰动强度，在线自适应调节 LADRC 的带宽与增益参数，实现响应速度与稳定性的动态平衡。
3.  提出**跨时间样本增强机制**（Cross-time Sample Augmentation），结合过去状态重播（Past State Replay）、动作保持（Action Hold）与 N 步回报（N-step Bootstrapping），显著解决了连续控制任务中样本相关性强、回报延迟导致的训练低效问题。

### 1.4.2 规划层：任务分离的元训练协同规划方法
针对协同避障中的多目标冲突问题，提出了“避障—合作”任务分离的双流网络架构。
1.  设计**三编码器 + 双注意力网络**，分别处理自身、障碍物与邻机信息，显式解耦风险交互与协作交互。
2.  引入**增长注意力模式**（Growth Attention Mode），随训练阶段逐步扩展关注范围与网络容量，兼顾早期训练稳定性和后期表达能力。
3.  采用**分阶段元训练策略**，按照“基础避障→协同编队→复杂融合”的课程体系进行训练，并通过一致性约束机制协调双输出器的决策冲突。

### 1.4.3 系统级机制：分层金字塔经验池与优先回放
针对多阶段训练中的遗忘与效率问题，设计了系统级的经验管理机制。
1.  构建**分层金字塔经验池**（Hierarchical Pyramid Replay Buffer），按训练阶段和任务难度对经验进行分层存储与管理，确保各阶段关键样本的留存。
2.  引入改进的**优先经验回放（PER）**策略，结合 TD 误差与任务特定指标（如碰撞风险、队形误差）计算优先级，大幅提升稀疏高价值样本的利用率。

## 1.5 本文创新点

1.  **提出了一种规划—控制深度耦合的分层协同控制框架**。明确定义了层间接口与交互协议，通过底层鲁棒控制为上层规划提供稳定的执行模型，解决了传统分层方法中层间失配的问题。
2.  **设计了 RL-LADRC 参数自适应控制算法及其跨时间样本增强机制**。将 LADRC 的模型无关性与 RL 的自适应能力结合，并通过结构化的样本增强策略，有效克服了控制层训练的样本低效与抖动问题。
3.  **提出了任务分离的协同规划网络与增长注意力机制**。通过显式分离避障与合作通道，解决了多目标优化的梯度冲突；增长注意力机制使得策略能够适应从简单到复杂的任务演进，提升了模型的可扩展性。
4.  **构建了分层金字塔经验池与多维优先回放策略**。从系统层面解决了课程学习中的灾难性遗忘问题，实现了在长周期训练过程中样本效率与策略稳健性的双重提升。

## 1.6 论文结构安排
本文共分为五章，具体安排如下：
*   **第一章**：绪论。阐述研究背景、挑战、现状，概括本文的研究内容与创新点。
*   **第二章**：系统建模与算法基础。建立四旋翼动力学模型，定义仿真任务与评价指标，介绍 RL、LADRC 及分层学习的基础理论。
*   **第三章**：运动控制层设计。详细阐述 RL-LADRC 控制器结构、状态/动作空间设计及跨时间样本增强机制，并通过对比实验验证其性能。
*   **第四章**：规划策略层设计。详细描述任务分离网络结构、分阶段元训练流程及金字塔经验池机制，并在多场景下验证协同避障效果。
*   **第五章**：总结与展望。总结全文工作，分析现有局限性，并对未来研究方向进行展望。
