# 基于分层强化学习的多无人机动态目标围捕协同控制策略研究

**摘要**
随着无人机技术的飞速发展，多无人机协同系统在复杂环境下的应用需求日益增长。然而，实际任务中存在的强气动干扰、模型参数不确定性以及多机间的避障与协作冲突，对控制系统的鲁棒性与智能化水平提出了严峻挑战。本文提出了一种“规划—控制”深度耦合的分层强化学习框架，旨在解决复杂动态环境下的多无人机协同控制问题。首先，针对底层控制的稳定性难题，设计了基于深度强化学习（DRL）参数自适应的线性自抗扰控制（LADRC）策略，并提出跨时间信息增强机制以提升训练效率。其次，针对上层规划的多目标冲突与扩展性问题，提出了基于任务分离与渐进式增长注意力的协同规划方法。最后，通过分层金字塔经验池与联合仿真实验，验证了所提框架在系统级协同任务中的有效性与鲁棒性。

**关键词**：多无人机协同；分层控制；线性自抗扰控制；深度强化学习；任务分离；增长注意力

# 第五章 联合仿真与系统级验证 (Joint Simulation)

## 5.1 联合仿真设置
本章将第三章的控制器与第四章的规划器**串联**，在极具挑战性的 **“强风扰 + 密集障碍”** 场景下进行全系统测试。
*   **场景**：10架无人机围捕动态目标，环境中存在随机风场（阵风等级 5级）。
*   **对比方案**：
    *   方案 A：本文规划 + PID 控制（基线）
    *   方案 B：本文规划 + 固定 LADRC（进阶）
    *   方案 C：本文规划 + RL-LADRC（本文完整方案）

## 5.2 结果分析
### 5.2.1 轨迹跟踪精度对协作的影响
实验发现，方案 A (PID) 由于抗风能力差，导致无人机实际位置偏离规划轨迹，进而引发 **“多米诺骨牌效应”** —— 一架无人机偏离导致邻居避障，最终队形溃散。
方案 C (RL-LADRC) 能够将跟踪误差控制在 0.1m 以内，保证了规划层指令的精确执行，队形保持最稳。

### 5.2.2 系统鲁棒性评估
在风速突变时刻，方案 B 的规划层会出现震荡（因为底层反馈了较大的状态误差），而方案 C 通过底层参数自适应迅速抑制了扰动，上层规划几乎未受影响。这证明了 **分层架构中底层鲁棒性的重要性**。
