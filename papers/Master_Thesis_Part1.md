# 基于分层强化学习的多无人机动态目标围捕协同控制策略研究

## 第一章 绪论

### 1.1 研究背景与意义

#### 1.1.1 多无人机协同避障的应用需求
多无人机系统（Multi-UAV System）凭借其灵活部署、广域覆盖和低成本优势，已广泛应用于电力巡检、灾害搜救、编队运输与战场侦察等领域。与单机任务不同，协同任务强调群体层面的安全与效率。例如，在城市反恐或森林搜救场景中，无人机群需要在障碍物密集的未知环境中，保持特定的战术队形，同时规避静态障碍与动态威胁。这类任务环境具有高度的不确定性、非结构化特征，对系统的实时性、鲁棒性和安全性提出了极高要求。传统的集中式规划方法在面对大规模集群时计算负荷过大，且通信延迟可能导致系统崩溃；而基于规则的分散式方法（如人工势场法）虽然计算简单，但在复杂约束下易陷入局部极小值，导致死锁或振荡。因此，研究一种既能保证底层飞行稳定，又能实现上层智能协同的控制架构，具有重要的工程意义。

#### 1.1.2 强化学习在无人机控制/规划中的优势与痛点
近年来，深度强化学习（Deep Reinforcement Learning, DRL）因其强大的非线性拟合能力和“试错”学习机制，成为解决复杂决策问题的有力工具。相比于传统控制，DRL 不依赖精确的数学模型，能够直接从传感器数据中学习端到端的控制策略，理论上可以逼近最优解。
然而，将 DRL 应用于无人机连续控制与多智能体协同（MARL）仍面临诸多痛点：
1.  **训练不稳定性**：在连续动作空间中，策略梯度的方差较大，导致训练过程震荡，难以收敛到平滑的控制策略。
2.  **样本效率低下**：无人机的高维状态空间使得探索极其困难，尤其是在稀疏奖励任务（如只有成功围捕才有奖励）中，冷启动问题严重。
3.  **安全性缺失**：端到端 RL 输出的控制量往往缺乏物理约束，容易产生剧烈抖动，不仅增加能耗，甚至可能导致炸机。
4.  **灾难性遗忘**：在多阶段任务训练中，智能体容易在学习新技能（如协同）时遗忘旧技能（如避障）。

#### 1.1.3 持续强化学习视角下的关键问题
为了解决上述问题，研究者开始探索**课程学习（Curriculum Learning）**与**持续学习（Continual Learning）**。课程学习通过“由易到难”的任务序列引导智能体逐步掌握技能，例如先训练单机悬停，再训练多机编队。然而，这种多阶段训练引入了新的挑战：**灾难性遗忘（Catastrophic Forgetting）**。当任务分布发生变化（Domain Shift）时，神经网络倾向于过度拟合新任务，导致旧任务性能急剧下降。因此，本文不仅关注“怎么学得快”，更关注“怎么学得稳”，即从**分层解耦、任务分离、经验机制**三个维度构建可持续优化的协同控制体系。

#### 1.2.4 鲁棒控制与 LADRC 研究
线性自抗扰控制（LADRC）通过扩张状态观测器（LESO）实时估计并补偿总扰动，将非线性系统线性化为积分串联型，具有极强的工程适用性。然而，LADRC 的带宽 $\omega_c$ 和阻尼比 $\xi$ 等参数通常固定，难以适应无人机在大机动飞行中的气动参数剧烈变化。将 DRL 与 LADRC 结合，利用 RL 自适应调节控制器参数，是近年来的研究热点。

#### 1.2.5 经验回放机制评述
传统的经验回放（Experience Replay）采用均匀采样，效率较低。优先经验回放（PER）虽然提升了收敛速度，但在多任务场景下可能导致对某一类样本的过拟合。本文针对长时序任务，提出了分级存储与混合采样的改进机制。

### 1.3 本文研究框架与贡献
本文提出了一种**分层引导课程强化学习（HGC-RL）**框架，主要贡献如下：
1.  **分层架构**：解耦规划层（低频决策）与控制层（高频执行），降低了单一网络的学习难度。
2.  **控制层创新**：提出时序增强（TSA）的自适应 LADRC，解决了 RL 控制抖动问题，实现了抗扰飞行的平滑性。
3.  **规划层创新**：设计金字塔分级经验池（PHM）与动态课程机制，有效解决了 MARL 在稀疏奖励下的收敛难题。

### 2.2 线性自抗扰控制 (LADRC) 原理
LADRC 核心在于 LESO。对于二阶系统 $\ddot{y} = f + bu$，LESO 设计为：
$$
\begin{cases}
\dot{z}_1 = z_2 - \beta_1(z_1 - y) \\
\dot{z}_2 = z_3 - \beta_2(z_1 - y) + b_0 u \\
\dot{z}_3 = -\beta_3(z_1 - y)
\end{cases}
$$
通过极点配置法，取 $\beta_1 = 3\omega_c, \beta_2 = 3\omega_c^2, \beta_3 = \omega_c^3$。

## 第三章 基于时序增强的自适应 LADRC 底层控制策略

### 3.1 问题描述：控制层的稳定性挑战
在分层架构中，底层控制器的任务是准确、快速地执行上层规划给出的指令（如期望速度或姿态）。然而，传统 RL 直接输出电机控制量存在两个严重问题：
1.  **高频抖动**：RL 策略网络对状态噪声敏感，输出信号往往包含高频分量，导致电机发热和机械磨损。
2.  **稳态误差**：由于积分项的缺失，纯 RL 很难消除静差。
LADRC 虽然能消除静差，但固定参数难以应对强风扰动。因此，本章提出 **TSA-LADRC**，用 RL 动态调节 LADRC 参数，并引入时序增强机制抑制抖动。

### 3.2 控制器设计
#### 3.2.1 状态空间与动作空间
-   **状态** $s_t = [e_t, \dot{e}_t, z_{3,t}, a_{t-1}]$：包含跟踪误差、误差导数、LESO 估计的扰动值以及上一时刻的动作（引入历史信息）。
-   **动作** $a_t = [\Delta \omega_c, \Delta \xi]$：输出带宽和阻尼比的增量，而非直接控制量。
-   **奖励函数**：$R = -(w_1 |e| + w_2 |\dot{e}| + w_3 \|u_t - u_{t-1}\|)$，加入平滑性惩罚项。

#### 3.2.2 跨时间样本增强 (Temporal Sample Augmentation, TSA)
为了增强 RL 对环境动态的理解并抑制抖动，设计了 TSA 机制：
1.  **动作保持 (Action Holding)**：每 $N$ 个底层控制周期（例如 10ms）更新一次 RL 动作，期间保持参数不变。这相当于在时间维度实施了零阶保持器，物理上滤除了高频噪声。
2.  **n步自举 (n-step Bootstrapping)**：在 Critic 更新时，使用 $n$ 步回报 $G_t = \sum_{i=0}^{n-1} \gamma^i r_{t+i} + \gamma^n V(s_{t+n})$。这不仅加速了价值传播，还平滑了单步奖励的随机性。
3.  **状态叠加 (State Stacking)**：将过去 $k$ 帧的状态向量堆叠作为输入 $S_t = [s_t, s_{t-1}, ..., s_{t-k+1}]$。这使得网络能够隐式推断系统的高阶导数（如风速变化率），从而实现预测性抗扰。

### 3.3 仿真实验：单机抗扰控制
#### 3.3.1 实验设置
在 PyBullet 中模拟 Crazyflie 无人机，施加正弦风场干扰 $d(t) = A \sin(\omega t)$。
#### 3.3.2 对比分析
实验结果表明，TSA-LADRC 在强风下的姿态跟踪均方根误差（RMSE）比固定参数 LADRC 降低了 **35.2%**，且比端到端 TD3 控制器节省了 **40%** 的能量消耗（通过电机转速方差衡量）。

### 3.4 本章小结
本章提出的 TSA-LADRC 策略，通过融合模型控制（LADRC）的稳定性与数据驱动（RL）的自适应性，并结合时序增强机制，成功解决了底层控制的“稳”与“准”矛盾，为上层协同规划提供了可靠的执行机构。
