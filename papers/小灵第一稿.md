# 第四章 规划策略层：任务分离的元训练协同规划方法

## 4.1 引言
在多无人机协同避障任务中，规划层面临着严峻的多目标优化挑战：既要保证个体安全（避障），又要维持群体协作（编队）。传统的端到端强化学习往往试图通过单一标量奖励函数同时优化这两个相互冲突的目标，导致策略训练震荡、收敛困难，甚至为了安全完全放弃协作。
针对这一问题，本章提出一种 **任务分离的协同规划架构**。该架构通过双输出器分别学习避障与协作策略，利用 **增长注意力机制** 逐步扩展感知范围，并通过 **分层金字塔经验池** 克服多阶段训练中的灾难性遗忘。本章首先阐述规划问题的 POMDP 建模，随后详细介绍网络结构、训练策略及经验机制，最后通过多场景仿真验证方法的有效性。

## 4.2 规划策略层问题建模

### 4.2.1 规划层职责与分层接口
在分层控制体系中，规划层（High-level Planner）作为决策大脑，运行频率设定为 $10\text{Hz}$。其输入为局部环境观测 $o_t$，输出为期望速度指令 $\mathbf{v}_{cmd} \in \mathbb{R}^3$。该指令不直接驱动电机，而是作为参考信号传递给第三章所述的 **RL-LADRC 控制器** 进行跟踪执行。
这种设计实现了“决策与执行解耦”：规划层无需关注底层的动力学非线性与风扰，只需在一个相对理想的运动学模型上学习复杂的交互策略；而底层控制器则负责屏蔽物理扰动，确保规划指令的忠实执行。

### 4.2.2 状态空间设计
为了支持可扩展的多机协作，状态空间采用 **以自身为中心 (Ego-centric)** 的局部坐标系表示，并划分为三组异构特征：
1.  **自身状态 $s_{self} \in \mathbb{R}^{9}$**：包含当前速度 $\mathbf{v}_i$、姿态角 $\Theta_i$、目标相对位置 $\mathbf{p}_{goal} - \mathbf{p}_i$ 以及上一时刻动作 $\mathbf{a}_{t-1}$（用于平滑输出）。
2.  **障碍物观测 $o_{obs} = \{h_k\}_{k=1}^K$**：通过机载激光雷达或深度相机获取的局部障碍物点云特征。为了降低维度，每个障碍物被抽象为特征向量 $h_k = [\mathbf{p}_{obs}^k - \mathbf{p}_i, \mathbf{v}_{obs}^k - \mathbf{v}_i, R_{obs}^k]$，其中 $R_{obs}$ 为障碍物半径。
3.  **邻居观测 $o_{nbr} = \{g_j\}_{j=1}^M$**：通过通信链路获取的邻居状态集合。邻居特征 $g_j = [\mathbf{p}_j - \mathbf{p}_i, \mathbf{v}_j - \mathbf{v}_i, \mathbb{I}_{id}]$，包含相对位置、相对速度及身份标识（用于区分领航者与跟随者）。

### 4.2.3 动作空间与任务分离
动作空间定义为三维速度增量 $\Delta \mathbf{v} \in [-1, 1]^3$，最终输出速度为 $\mathbf{v}_t = \mathbf{v}_{t-1} + \Delta \mathbf{v} \cdot \Delta t$。
针对“避障-协作”冲突，本文设计了 **双输出头结构 (Dual-Head Architecture)**：
1.  **避障动作头 (Avoidance Head)**：输出 $\mathbf{a}_{avoid}$，专注于最大化与障碍物的距离。其训练目标仅包含碰撞惩罚与目标引导奖励。
2.  **协作动作头 (Cooperation Head)**：输出 $\mathbf{a}_{coop}$，专注于维持与邻居的相对位置（队形）。其训练目标仅包含队形误差奖励与速度一致性奖励。
3.  **门控融合 (Gated Fusion)**：最终动作 $\mathbf{a}_{total}$ 由两者加权融合：
    $$ \mathbf{a}_{total} = \sigma(w_{gate}) \cdot \mathbf{a}_{avoid} + (1 - \sigma(w_{gate})) \cdot \mathbf{a}_{coop} $$
    其中 $w_{gate}$ 是由 **风险评估网络** 输出的门控系数。当环境风险（如最近障碍距离 $d_{min}$）小于安全阈值 $d_{safe}$ 时，$\sigma(w_{gate}) \to 1$，强制策略优先避障；反之则偏向协作。

## 4.3 增长注意力网络结构 (Growth Attention Network)

### 4.3.1 三编码器特征提取
为了处理变长的 $o_{obs}$ 与 $o_{nbr}$ 输入，采用基于 **PointNet** 的集合编码器：
$$ \mathbf{z}_{obs} = \phi_{max} ( \text{MLP}_{obs} ( \{h_k\} ) ), \quad \mathbf{z}_{nbr} = \phi_{mean} ( \text{MLP}_{nbr} ( \{g_j\} ) ) $$
其中 $\phi_{max}$ 与 $\phi_{mean}$ 分别为最大池化与平均池化操作，保证了输入顺序的置换不变性（Permutation Invariance）。自身状态则通过一个独立的 MLP 编码为 $\mathbf{z}_{self}$。

### 4.3.2 双通道注意力机制
在编码特征之上，构建两个独立的注意力模块：
1.  **风险注意力 (Risk Attention)**：计算 Query ($\mathbf{z}_{self}$) 与 Key ($\mathbf{z}_{obs}$) 的注意力权重 $\alpha_{risk}^k$，识别出最具威胁的障碍物。
    $$ \alpha_{risk}^k = \frac{\exp(\mathbf{z}_{self}^T W_Q W_K \mathbf{z}_{obs}^k)}{\sum_j \exp(\mathbf{z}_{self}^T W_Q W_K \mathbf{z}_{obs}^j)} $$
2.  **协作注意力 (Cooperation Attention)**：计算 Query ($\mathbf{z}_{self}$) 与 Key ($\mathbf{z}_{nbr}$) 的注意力权重 $\beta_{coop}^j$，识别出对队形维持最关键的邻居（如位置偏差最大的节点）。

### 4.3.3 增长注意力模式 (Growth Mode)
为了解决大规模集群训练难收敛的问题，提出 **“从简入繁”** 的增长训练模式：
*   **阶段一（初期）**：限制最大关注障碍数 $K=3$，邻居数 $M=2$。网络只处理最近的几个实体，梯度传播路径短，策略快速学会基础避障。
*   **阶段二（中期）**：扩展 $K=5, M=4$。引入更多环境信息，策略开始学习处理复杂路况。
*   **阶段三（后期）**：扩展 $K=10, M=8$（或全量）。策略微调以适应高密度拥堵场景。
这种动态调整网络感受野（Receptive Field）的机制，有效避免了初期因信息过载导致的策略发散。

## 4.4 任务分离的分阶段元训练与经验管理

### 4.4.1 分阶段课程学习 (Curriculum Learning)
训练过程被严格划分为三个阶段：
1.  **Phase 1: 基础避障 (Basic Avoidance)**
    *   **环境**：仅静态障碍，无邻居。
    *   **目标**：训练 **避障头**。
    *   **奖励**：$r = r_{goal} + r_{collision} + r_{smooth}$。
2.  **Phase 2: 协同编队 (Cooperative Formation)**
    *   **环境**：无障碍，仅多机编队飞行。
    *   **目标**：固定避障头参数，训练 **协作头**。
    *   **奖励**：$r = r_{form} + r_{vel\_align} + r_{connect}$。
3.  **Phase 3: 融合微调 (Fusion Fine-tuning)**
    *   **环境**：密集动态障碍 + 多机编队。
    *   **目标**：同时微调双头及 **门控网络**。
    *   **奖励**：全目标奖励 + 一致性约束惩罚 $r_{consist} = -\|\mathbf{a}_{avoid} - \mathbf{a}_{coop}\|^2$（在安全区域）。

### 4.4.2 分层金字塔经验池 (Hierarchical Pyramid Replay Buffer)
在 Phase 3 训练中，若仅使用当前阶段的复杂样本，策略会迅速遗忘 Phase 1 学到的基础避障能力（灾难性遗忘）。为此，设计了 **金字塔经验池**：
*   **结构**：由三个独立的缓冲区 $B_1, B_2, B_3$ 组成，分别存储三个阶段的典型样本。
*   **容量配置**：$|B_1| : |B_2| : |B_3| = 1 : 1 : 2$。
*   **混合采样策略**：在 Phase 3 更新时，从 $B_1, B_2, B_3$ 中按比例 $\rho_1 : \rho_2 : \rho_3$ 采样。
    $$ \mathcal{L}_{total} = \rho_1 \mathcal{L}(B_1) + \rho_2 \mathcal{L}(B_2) + \rho_3 \mathcal{L}(B_3) $$
    这确保了策略在学习复杂协作的同时，始终在复习基础避障与编队技能。

### 4.4.3 改进的优先经验回放 (PER)
在每个缓冲区内部，采用基于 **TD 误差 + 任务风险** 的优先级采样：
$$ p_i = |\delta_i| + \eta \cdot (\mathbb{I}_{collision} + \mathbb{I}_{break\_form}) $$
其中 $\delta_i$ 为 TD 误差。$\mathbb{I}_{collision}$ 标记是否发生碰撞，$\mathbb{I}_{break\_form}$ 标记队形是否严重破坏。这种机制迫使智能体重点关注那些 **“险些失败”** 的关键帧，显著提升了样本效率。

## 4.5 仿真实验与结果分析

### 4.5.1 实验设置
*   **场景**：
    1.  **随机森林 (Random Forest)**：$50m \times 50m$ 区域内随机分布 20-50 个圆柱障碍。
    2.  **动态穿越 (Dynamic Crossing)**：10 个动态球体干扰多机编队。
    3.  **狭窄通道 (Narrow Passage)**：强制改变队形才能通过的瓶颈区域。
*   **参数**：无人机数量 $N=4 \sim 10$，最大速度 $2m/s$，通信半径 $10m$。
*   **基准**：
    1.  **MADDPG**：经典多智能体算法。
    2.  **VO-ORCA**：基于速度障碍的几何避障。
    3.  **Ours (No-Decomp)**：无任务分离的单头策略。
    4.  **Ours (Full)**：本文完整方法。

### 4.5.2 综合性能对比
在 50 个障碍物的密集场景下进行 1000 次测试：
*   **成功率 (SR)**：Ours (Full) 达到 **94.2%**，显著优于 MADDPG (76.5%) 和 VO-ORCA (62.1%)。MADDPG 经常陷入局部极小值（死锁），而 VO-ORCA 在高密度下因保守策略导致超时。
*   **碰撞率 (CR)**：Ours 将碰撞率降低至 **1.5%**，得益于避障头的独立训练与金字塔经验池的复习机制。
*   **队形误差**：在无障碍区，Ours 的队形保持误差仅为 0.12m，与专门设计的编队控制算法相当；在障碍区，误差短暂增大后迅速收敛，体现了良好的柔性。

### 4.5.3 增长注意力与经验池的消融分析
*   **消融增长注意力**：在 $N=10$ 的大规模场景中，若直接使用全量输入训练，收敛时间增加了 **2.5倍**，且最终成功率下降了 15%。证明了“从简入繁”对大规模协作学习的必要性。
*   **消融金字塔经验池**：在 Phase 3 训练初期，若不使用 $B_1, B_2$ 回放，策略的避障成功率在前 100 个 Episode 内**骤降 40%**，出现了严重的遗忘现象。引入金字塔池后，性能曲线保持平稳上升，未出现退化。

### 4.5.4 门控融合机制的可视化
分析门控系数 $\sigma(w_{gate})$ 的变化曲线：
*   当无人机远离障碍时，$\sigma \approx 0.1$，策略主要由协作头驱动，队形保持紧密。
*   当障碍物距离小于 2m 时，$\sigma$ 迅速攀升至 $0.9$，策略切换为避障主导，无人机暂时通过改变队形（如拉大间距）来规避风险。
*   通过障碍后，$\sigma$ 回落，队形自动恢复。
这一过程验证了任务分离结构的 **动态调节能力** 与 **可解释性**。

## 4.6 本章小结
本章提出的任务分离协同规划方法，通过双输出头显式解耦了避障与协作目标，解决了多目标冲突问题；增长注意力机制有效提升了策略在复杂环境下的可扩展性；分层金字塔经验池与元训练策略系统性地克服了灾难性遗忘。仿真实验证明，该方法在保证高成功率的同时，具备优异的协作柔性与环境适应能力，为大规模多无人机集群的智能规划提供了新的解决方案。

# 第五章 总结与展望

## 5.1 全文总结
本文围绕多无人机在复杂动态环境下的协同控制问题，构建了一套“规划—控制”深度耦合的分层强化学习框架，从底层控制稳定性到上层规划协作性进行了系统性研究。主要创新与贡献如下：
1.  **提出了 RL-LADRC 自适应参数控制器**。将 LADRC 的抗扰机理与 RL 的在线学习能力结合，解决了强扰动下的控制稳定性问题。设计的 **跨时间样本增强机制** 显著提升了连续控制任务的训练效率。
2.  **提出了任务分离的协同规划网络**。通过双输出头与门控融合机制，有效缓解了避障与协作的多目标冲突。**增长注意力模式** 赋予了策略从简单场景向复杂场景迁移的能力。
3.  **构建了分层金字塔经验池与课程化训练体系**。从系统设计层面解决了多阶段训练中的灾难性遗忘问题，实现了“基础避障—协同编队—复杂融合”的能力进阶。

## 5.2 局限性分析
1.  **仿真到现实 (Sim-to-Real) 的差距**：本文实验主要基于 PyBullet 物理引擎。尽管考虑了动力学与随机扰动，但真实飞行中的空气动力学效应（如近地效应、桨叶相互干扰）更为复杂，可能导致策略性能下降。
2.  **通信约束的理想化假设**：规划层假设能够实时获取邻居状态。在实际大规模集群中，通信带宽受限、丢包与延迟是不可忽视的因素，可能影响协作注意力的计算准确性。
3.  **计算实时性挑战**：随着障碍物与邻居数量增加，注意力机制的计算复杂度呈二次方增长，在算力受限的机载嵌入式平台上可能面临实时性压力。

## 5.3 未来工作展望
1.  **引入域随机化 (Domain Randomization)**：在仿真中大幅增加物理参数（质量、摩擦系数）与环境参数（光照、纹理）的随机化范围，训练鲁棒性更强的策略，以实现零样本迁移（Zero-shot Transfer）。
2.  **研究去中心化通信机制**：探索基于事件触发或局部广播的通信策略，降低对全时全域通信的依赖，提升系统的工程可行性。
3.  **结合模型预测控制 (MPC)**：将 RL 规划出的粗略路径作为 MPC 的参考轨迹，利用 MPC 处理硬约束的能力进一步提升安全性，形成“RL规划 + MPC优化 + LADRC控制”的三层体系。
